本科毕业设计（论文）· 开题报告

基于 Mamba 的
无线通信调制方式识别方法研究

学科方向：通信工程 / 人工智能 研究类型：应用基础研究

一、研究目的与意义

1.1 研究背景

调制方式识别（Automatic Modulation Classification, AMC）是认知无线电、频谱监测、电磁频谱战中的关键使能技术。深度学习方法已成为该领域主流，但现有架构存在明显的能力断层：

  1. CNN / CLDNN / ResNet：通过局部卷积感受野提取波形特征，效率高，但受限于固定大小的卷积核，难以建模长程时序依赖，在低信噪比（SNR < 0 dB）下性能急剧下降；
  2. Transformer / LLM：全局注意力可建模长程依赖，但注意力计算复杂度随序列长度平方增长，参数量庞大（亿级至十亿级）、训练推理成本高，难以部署于资源受限的频谱监测设备。

Mamba 状态空间模型（State Space Model, SSM）于 2023 年提出，其选择性扫描机制（Selective Scan）将序列建模复杂度从 O(N²) 降至 O(N)，兼具长程依赖建模能力与线性计算效率。近两年，MAMCA、AWMN 等工作已将 Mamba 引入自动调制识别，并展现出良好的低信噪比鲁棒性和轻量化潜力。因此，Mamba 为缓解“CNN 长程建模能力有限、Transformer 长序列计算开销较高”的矛盾提供了新的候选架构。

1.2 研究目的

本课题以 Mamba 状态空间模型为核心，研究高效、鲁棒的调制识别方法，系统回答以下三个问题：

  1. 如何将 Mamba 的选择性状态空间机制与 IQ 信号的局部时序特征有效结合，构建轻量高性能的调制识别网络？（架构设计问题）
  2. 相比 CNN、Transformer 两类主流基线，Mamba 模型在低信噪比场景下的性能增益有多少？增益来自何处？（性能对标与机理分析问题）
  3. 如何通过特征增强与训练策略（如小波变换、注意力门控、数据增强），进一步释放 Mamba 架构在低样本、跨信道场景下的潜力？（优化提升问题）

全部实验统一采用 RML2018.01a 公开数据集。该数据集包含 24 种数字与模拟调制方式、26 个信噪比档位（-20～30 dB，步进 2 dB），共 2,555,904 条长度为 1024 的复数 IQ 序列，可为 Mamba 的长序列建模能力提供较充分的验证条件。

1.3 研究意义

  • 理论意义：为"长序列信号的高效建模"这一核心问题提供 Mamba 方案的系统验证与机理分析，推动状态空间模型在物理层信号处理领域的落地研究。
  • 应用意义：Mamba 模型百万级参数量、线性推理复杂度的特性，使其天然适配边缘频谱监测设备，研究成果具备直接工程转化价值。
  • 个人训练意义：覆盖信号处理、序列建模、深度学习三大知识模块，且开源代码丰富，实验可控性强，适合本科阶段完成有深度的研究。

二、研究内容

2.1 基于 Mamba 的调制识别总体架构设计

设计"Mamba 主干 + 局部特征增强"的总体网络架构：

  • 信号输入层：直接接收 2×N 维原始 IQ 序列（不图像化，避免信息损耗）；
  • 局部特征提取层：浅层 CNN / 小波变换层提取符号级局部模式；
  • Mamba 编码层：堆叠 2~6 层选择性状态空间块（Selective SSM Block），建模长程时序依赖；
  • 分类头：全局池化 + 全连接层输出调制类别。

2.2 局部—全局双分支特征融合机制研究

  • 研究 TCN-Mamba 并行双分支结构：TCN 分支负责局部时序模式，Mamba 分支负责长程依赖，特征在分类前融合；
  • 研究自适应小波 + Mamba混合方案（借鉴 AWMN 思路）：用小波变换提供多分辨率时频先验，弥补纯数据驱动模型的物理可解释性；
  • 对比"串行堆叠"与"并行融合"两种结合方式对性能的影响。

2.3 低信噪比鲁棒性增强方法

  • 输入级增强：信道噪声 augment（随机加噪、频偏/相偏扰动、多径衰落仿真）提升训练数据多样性；
  • 结构级增强：在去噪单元（Denoising Unit）或门控注意力辅助下，抑制噪声主导的长程依赖干扰；
  • 损失级增强：引入标签平滑与难例挖掘（Focal Loss），聚焦易混淆调制对（如 16QAM vs 64QAM）。

2.4 系统化对照实验

2.5 机理分析与消融实验

  • 可视化 Mamba 隐藏状态的激活模式，解释其对不同调制类型（幅度类/相位类/频率类）的响应差异；
  • 消融实验：逐一移除局部特征层、去噪单元、长程依赖模块，量化各组件贡献；
  • 序列长度敏感性分析：从原始 1024 点序列中按统一规则截取 N ∈ {128, 256, 512, 1024} 的子序列，对比识别精度与计算耗时。

四、创新点

  1. 架构创新——局部与长程依赖的双分支协同建模：针对 IQ 信号"局部波形模式 + 长程符号依赖"的双重结构特性，设计 TCN-Mamba 并行双分支网络，在本科层面实现 CNN 局部感受野与 SSM 全局建模能力的首个系统性融合验证。
  2. 方法创新——面向低信噪比的增强型 Mamba 调制识别：将去噪单元 / 门控注意力机制引入 Mamba 调制识别管线，并配合信道噪声增强与 Focal Loss 难例挖掘训练策略，针对性改善易混淆调制对在低 SNR 下的区分度。
  3. 实验创新——CNN / Transformer / Mamba 三类架构的统一对标：在同一数据集、同一训练协议、同一测试协议下，首次（本科层面）给出三类序列建模架构在调制识别任务上的完整精度—效率权衡曲线，形成具有选型参考价值的方法论结论。
